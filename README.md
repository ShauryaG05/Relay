# Relay

**Relay** is a secure, lightweight system that lets you operate and monitor your macOS laptop from any mobile or desktop web browser.

---

## 🏛 Architecture Overview

The repository is organized as an npm workspaces monorepo:

```
Relay/
├── packages/
│   └── protocol/        # Shared TypeScript message envelopes, command schemas & Zod validators
├── apps/
│   ├── gateway/         # Standalone Node.js server with WebSocket multiplexing & MongoDB state
│   ├── agent/           # Background macOS daemon running local command handlers & LaunchAgent
│   └── web/             # Next.js 15 responsive mobile web dashboard (Tailwind, Lucide)
├── Requirements.md      # Functional & Non-Functional specifications
├── Design.md            # Technical Architecture and Security Design
└── Implementation_Plan.md # Phased execution breakdown
```

### Key Security Decisions

1. **Outbound-Only Connections**: The macOS agent connects **outward** to the Gateway over WebSocket. No inbound ports are opened on the Mac, avoiding port-forwarding and keeping the machine off the public internet.
2. **Fixed Command Set**: The Gateway and Agent never pass raw shell strings. Every action (`power.lock`, `files.list`, `process.kill`, etc.) has a dedicated handler and strict schema validation.
3. **Server-Enforced Destructive Action Confirmations**: High-risk commands (`power.restart`, `power.shutdown`, `process.kill`) require a cryptographic confirmation token generated by the server, bound to the device, action, and parameter hash, valid for 30 seconds, and consumed on first use.
4. **Canonical Path Protection**: The file browser strictly enforces an allowlist (`allowedFolders`). Every path is resolved and followed through symlinks (`fs.realpathSync`), and verified using whole-segment checks to prevent directory traversal (`..`) or symlink breakouts.
5. **Secure Device Token Storage**: The pairing process issues a single-use code that generates a 256-bit cryptographically secure device token. The server stores only its SHA-256 hash, while the agent stores the raw token with restricted `0600` POSIX permissions.

## 🚀 Quick Start

### 1. Prerequisites
- **Node.js**: v20+ (tested on Node v24)
- **MongoDB**: Running locally at `mongodb://127.0.0.1:27017` or MongoDB Atlas
- **Operating System**: macOS (tested on macOS 15 Sequoia)

### 2. Install Dependencies & Build
```bash
# In the repository root
npm install
npm run build
```

### 3. Run Automated Tests
```bash
# Run unit & integration tests across all packages
npm test
```

### 4. Start the Gateway
```bash
# Runs the WebSocket and REST server on port 4000
npm run dev:gateway
```

### 5. Start the Web App
```bash
# Runs the Next.js responsive dashboard on port 3000
npm run dev:web
```
Open [http://localhost:3000](http://localhost:3000) on your phone or desktop.

### 6. Pair Your Mac
1. Open the Web App, register or log in, and tap **"Pair Mac"** to generate a 10-minute one-time pairing code (e.g. `ABCD-EFGH`).
2. Run the pairing command in Terminal on your Mac:
   ```bash
   node apps/agent/dist/cli.js pair <CODE> --gateway http://localhost:4000
   ```
3. Start the agent in the foreground:
   ```bash
   node apps/agent/dist/cli.js start
   ```
4. **(Optional) Run as a background LaunchAgent**:
   To ensure the agent automatically starts on macOS login and restarts on crashes:
   ```bash
   node apps/agent/dist/cli.js service install
   ```
   To remove:
   ```bash
   node apps/agent/dist/cli.js service uninstall
   ```

## 📱 Mobile-First Features

- **Responsive Viewport**: Fully optimized for mobile screens down to 360px with bottom navigation.
- **Power Actions**: Lock screen and sleep within 2 taps; restart and shut down with server-backed 30-second confirmation dialogs.
- **Live System Telemetry**: Real-time 2-second streaming of CPU load, memory usage, disk storage, battery percentage/charging state, and uptime.
- **Sandboxed File Browser**: Browse allowlisted folders, download files, and upload files directly from your phone.
- **Volume & Notifications**: Adjust system volume, toggle mute, and display macOS push notifications on your screen.
- **Append-Only Audit Log**: Every action, timestamp, IP address, and result is preserved for security inspection.
